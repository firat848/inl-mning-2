Beskriv skillnaden mellan vattenfallsmodellen och agil metodik.
När bör man använda vilken, och varför?     


Skillnaden mellan vattenfallsmodellen och agil metodik är att vattenfallsmodellen projektet görs innan det börjar att följa ett fast plan som senare inte går att ändra viktiga delar. Medan agil metodik är så följer man inte fast plan, man går sakta sakta varje del på ett mindre tempo. Alltså vattenfallsmodellen används när man har fast vägg man planerar alla steg förrän processen utan att ändra sitt vägg när man är 100 på vad man ska göra tydligt mål kan man säga medans agil metodik så arbetar man på ostabil tempo alltså man arbetar i små små delar där allting kan hända och där man inte har tydligt vägg kan man säga. 







Vad är ett Git-commit och varför är det viktigt?
Beskriv ett verkligt scenario där Git hjälper dig undvika problem.
En git commit är kod som du har sparat dina snaste ändringar varför de viktigt är för attt man inte sparar gamla kodder eller blandar koderna osånt. Git används för att kunna alltid gå tillbaka tilll dina tidigare använd version så när du råkar göra fel så kan du bara använda git för att gå tillbaka.
